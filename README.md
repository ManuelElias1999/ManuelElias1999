## Profile

<img align="right" width="215" src="assets/manuel-elias-profile.jpg" alt="Juan Manuel Elias Soria">

I'm **Manuel Elias**, a Blockchain Architect and Web3 developer from Bolivia with **5+ years of experience** designing and delivering blockchain products.

My work covers the full product lifecycle: system architecture, smart-contract development, protocol integrations and production delivery. I focus on turning complex blockchain infrastructure into secure products people can actually use.

- **Architecture:** on-chain/off-chain systems, distributed applications and API design
- **Smart contracts:** Solidity, Foundry, Hardhat, security and testing
- **Protocols:** Chainlink, Uniswap, Aerodrome, Aave and OpenZeppelin
- **Networks:** Ethereum, Base, Stacks, Stellar, Avalanche and Polygon
- **Leadership:** technical direction, developer education and Web3 communities
